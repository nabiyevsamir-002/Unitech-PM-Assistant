## 6. Key gotchas / operational notes (READ THESE)

- **After `prisma migrate` adds a column, RESTART the dev server** (`preview_stop` + `preview_start`). The running `next dev` holds the OLD generated Prisma client in memory → new field reads as `undefined` (looks like a DTO bug). This cost debugging time twice.
- **Reseeding invalidates the open browser session** (JWT holds a now-deleted user id). Approvals/time-logging then hit the friendly stale-user guard. Fix: log in fresh (see below).
- **Fresh login in the browser pane**: navigate `/api/auth/signout` → screenshot (it's 1:1 at 800px there) → click "Sign out" at ~(399,550) → navigate `/login` → click a demo-account button by `ref`. (Clicking the signout button raced/failed before because clicks need SCREENSHOT-pixel coords.)
- **Browser-pane clicks need SCREENSHOT-pixel coords** (often ~0.5× the reported viewport width due to DPR), NOT viewport coords. Clicking by `ref` is hit-or-miss; explicit `coordinate` from a fresh screenshot is reliable. `read_console_messages` buffer persists across navigations (stale errors look current).
- **Next 16 warns `middleware` is deprecated → prefer `proxy`**; `src/middleware.ts` still works (not migrated). Harmless dev-only "script tag" console warning from Next devtools.
- **Intl `az-AZ` date locale is missing in this runtime** → `src/lib/format.ts` builds `dd.mm.yyyy` manually via `formatToParts(en-GB)` + Asia/Baku tz. Don't revert to locale-string formatting (causes hydration mismatch).
- App's logical "today" is hardcoded to **2026-08-06** in seed + `context.ts`; overdue/due-today use real `new Date()`, so demo drifts slightly as real time passes.
